### Descripción del proyecto

El presente proyecto implementa una base de datos centralizada y una arquitectura distribuida utilizando información histórica de la Encuesta Nacional de Ocupación y Empleo (ENOE) correspondiente al periodo 2021–2025.

La solución desarrollada contempla:

* Diseño de base de datos en Tercera Forma Normal (3FN).
* Integración histórica de datos ENOE.
* Implementación de tablas catálogo.
* Fragmentación horizontal temporal.
* Construcción de nodos distribuidos.
* Consultas centralizadas y distribuidas.
* Validación de integridad de la fragmentación.
* Comparación de esquemas centralizados y distribuidos.
* Generación de respaldos completos.

### Estructura del repositorio

* 01_Documentación: documentación final del proyecto.

* 03_Capturas: evidencias y capturas de ejecución.
